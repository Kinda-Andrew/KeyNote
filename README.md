# KeyNote

Project hosted on a static page
Users can download files from the SongFiles folder for mp3 songs to play, 
Users can use the files from osuFiles for .osu files to attach to songs 

Suggested BPMs for the automapped songs included which do not have a .osu file
Body - Don Toliver: 180 BPM
Call Me Maybe: 135 BPM
Hotline Bling - Drake: 136 BPM
My Way - Frank Sinatra: 160

Users can also download the repository and open the HTML file
Users can use the existing song and .osu files downloaded with the repository 
Suggested BPMs for songs without .osu files are listed above
